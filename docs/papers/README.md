# Papers — documentación complementaria (no normativa)

Estos documentos conservan el fundamento histórico, cultural y religioso del
Calendario Gerarion como investigación y documentación complementaria.
**No son normativa de GUS**: el estándar solo usa el formato canónico de la
spec (`docs/spec/gus-2.1.0.md` ES / `docs/en/gus-2.1.0.md` EN normativo) y los
vectores de `vectors/`. Las discrepancias conocidas entre este material y el
kernel están registradas en `docs/history/errata-v1.2.md` (E-01..E-07).

- `drift-acotado.md` — demostración de la cota de drift (|Δ| < 7 días, para siempre).
- `lib-c-referencia.md` — referencia histórica de la librería C (corpus v1.2).

Creador único del Calendario Gerarion, de la lengua Nuvid y de la
investigación original: **Gerardo Loyola** (github.com/geroiloyola).
El estándar GUS lo mantiene el proyecto **verared** (futura fundación)
(github.com/verared), responsable del estándar a largo plazo.
